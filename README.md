# 搭伙儿｜合租生活管家

为年轻合租人群设计的轻量协作工具，覆盖费用 AA、清洁排班、公共物品登记提醒与室友公约管理。

## 功能

- 共同费用登记、自动均摊与一键结清
- 清洁任务轮换、分工展示与完成打卡
- 公共物品库存登记、消耗记录与低库存提醒
- 室友公约共同确认与新增提议
- AI 合租助手：自然语言理解、可编辑行动草案、确认执行、四模块联动与撤销
- 产品思考案例页：用户主流程、优先级取舍、AI 能力边界与评估指标
- 响应式桌面与移动端布局
- 使用浏览器本地存储保留演示操作

## 运行

直接打开 `index.html`，或使用任意静态文件服务器访问。

> 本项目为产品概念 MVP，示例人物与数据均为虚构。AI 识别在浏览器本地模拟，评估数字均为目标值而非线上成绩。
